# Loop de Jogo Central

O ciclo que traz o jogador de volta:

```
Abrir a app
    ↓
Ver o caminho (o que treinar hoje)
    ↓
Fazer um exercício (vídeo → praticar → temporizador)
    ↓
Concluir → ganhar XP + manter streak
    ↓
Desbloquear o próximo + ver o progresso subir
    ↓
(Fase 3) Desafiar/comparar com a equipa
    ↓
Voltar amanhã (não quebrar a corrente)
```

Este loop é o coração do MVP. Tudo o resto serve para o tornar mais forte.
