# Matriz de Funcionalidades (MoSCoW)

| Prioridade | Funcionalidade | Fase |
|---|---|---|
| ESSENCIAL | Escolher posição + gerar caminho | 1 (MVP) |
| ESSENCIAL | Exercícios com vídeo + descrição | 1 (MVP) |
| ESSENCIAL | Concluir exercício + ganhar XP | 1 (MVP) |
| ESSENCIAL | Streak diária + progresso visível | 1 (MVP) |
| IMPORTANTE | Rounds cronometrados | 2 |
| IMPORTANTE | Cartão de jogador (estilo FIFA) | 2 |
| DESEJÁVEL | Desafiar um colega / social real | 3 |
| DESEJÁVEL | Análise de vídeo por IA | 4 |
| DESEJÁVEL | Nutrição / mental / rotina | mais tarde ou nunca |

O **cartão de jogador** é o primeiro a acrescentar depois do MVP (é o que mais
prende o Nicolas na Footwork).
