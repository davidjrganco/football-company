# Sistema de Níveis

No MVP: desbloqueio **sequencial** de exercícios (um caminho linear).

Evolução (v2), inspirada na Footwork:
- **Níveis** que agrupam **fases**; cada fase agrupa vários exercícios.
- Troféu ao concluir uma fase.
- Cada **competência** (skill) sobe de nível de forma independente (ver
  `Player_Progression.md`).
