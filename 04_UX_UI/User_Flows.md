# Fluxos de Utilizador

Fluxos principais (implementados no protótipo Vertical Slice).

## Fazer um exercício (loop central)
```
Caminho → toca no nó atual ("COMEÇAR")
  → Ecrã do exercício (vídeo, descrição, dica, temporizador)
  → Iniciar temporizador → praticar
  → "Concluir · +30 XP"
  → Celebração (confetti + XP + streak)
  → volta ao Caminho: nó feito (✓), seguinte desbloqueado
```

## Ver progresso
```
Nav → Perfil → cartão (rating sobe) + streak/melhor/XP/exercícios feitos
```

## Futsal (secundário)
```
Nav → Futsal (separador discreto) → lista curta de exercícios de futsal
```

## Onboarding (F1 completo)
```
1.º arranque → escolher posição → caminho gerado → 1.º exercício
```
