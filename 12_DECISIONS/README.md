# 12 · Decisions (ADRs)

Registo de decisões no padrão **ADR (Architecture Decision Record)**.

**Regras:**
- Uma decisão por ficheiro: `ADR-XXXX-titulo.md`.
- **Nunca alterar** um ADR antigo. Para mudar, cria-se um novo ADR com
  `substitui: ADR-XXXX` e marca-se o antigo como `estado: Substituído`.
- Cada ADR tem: contexto, decisão, alternativas, consequências.

Modelo em `_TEMPLATES/Decision_Template.md`.
