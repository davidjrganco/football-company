# ADR-0003 — Documentação e fundações antes de código

**Estado:** Aceite  ·  **Data:** 2026-08-01

## Contexto
É um projeto para durar anos e para ensinar. A tentação de programar cedo é grande, mas prejudica clareza e qualidade.

## Decisão
Nenhum código de aplicação antes de os entregáveis do Sprint 001 (fundações) estarem concluídos. O Claude Code atua como Staff Engineer/Architect nesta fase.

## Alternativas consideradas
- Começar a programar já (rejeitado — sem fundações, cresce mal).

## Consequências
Ritmo inicial mais lento em código, mas base sólida, escalável e mantível. Risco a gerir: não deixar a documentação virar excesso — manter 'just enough' por sprint para o Nicolas não perder o entusiasmo.
