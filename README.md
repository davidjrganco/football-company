# Football Company — Founders Bible

> Repositório-empresa (não é só uma app). Projeto pai-e-filho: **David & Nicolas (14)**
> constroem uma app de treino de futebol inspirada na Footwork — semelhante ou melhor.
> Idioma do projeto: **PT-PT**. Construção no **Claude Code**.

## O que é este repositório
Isto não é um projeto de software normal — é a **Founders Bible** de uma empresa.
Primeiro construímos fundações (visão, produto, design, engenharia, marca) e só
depois código. Ver `MANIFESTO.md`, `PROJECT_CHARTER.md` e `GOLDEN_RULES.md`.
